# Briefs

The daily briefs, weekly reviews and 1:1 preps, newest first under this page. Each is computed from what is filed
(`wye ea brief …`), then an agent adds a few lines of judgment on top. The daily brief and the weekly review start on
their own (hook:ea.daily-brief, hook:ea.weekly-review); run any of them by hand from the workflows.
