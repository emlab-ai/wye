# Briefs

The daily briefs, weekly reviews and 1:1 preps, newest first under this page. Each is computed from what is filed
(`wye ea brief …`), then an agent adds a few lines of judgment on top. The weekly review starts on its own
(hook:ea.weekly-review); the daily brief is run by hand now — each morning the [Digest](module:ea-digest) gets a daily
summary instead (hook:ea.daily-summary). Run any of them from the workflows.
