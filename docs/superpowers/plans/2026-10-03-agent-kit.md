# Agent kit — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install Wye's skills and hooks into Claude Code, Codex and Cursor (globally or into one repo) from a first-run popup, Settings › Agents or `wye agents`; link a repo to a product with `/wye-init`; record an outside agent's conversation as a Wye session.

**Architecture:** One CommonJS module, `lib/agent-kit.js`, plans and applies installs (copies with a manifest, hook entries merged by a `wye hook` command prefix, a marked AGENTS.md section) and is used by the CLI directly and by the app through `createRequire`. The CLI gains `wye agents`, `wye products`, `wye hook`, and finds the product from `.wye/config.json`. The app gains `/api/agents`, a Settings › Agents panel, a first-run dialog, and *external* sessions (no process of Wye's) that the hooks open, checkpoint and close.

**Tech Stack:** Node (CommonJS in `lib/`, `bin/wye.js`), Next.js 16 route handlers and React client components in `packages/web`, vitest.

**Spec:** `docs/superpowers/specs/2026-10-03-agent-kit-design.md`

## Global Constraints

- Agents: `claude` (Claude Code), `codex` (Codex), `cursor` (Cursor), `agents-md` (the AGENTS.md / CLAUDE.md section).
- Skills shipped: every folder in `skills/` (`wye-agent`, `wye-context`, `wye-describe-module`, `wye-restore`, new `wye-init`).
- Destinations (global → local): `~/.claude/skills` → `<repo>/.claude/skills`; `~/.codex/skills` → `<repo>/.codex/skills`; `~/.cursor/skills` → `<repo>/.cursor/skills`; hooks in `~/.claude/settings.json` → `<repo>/.claude/settings.json`; `~/.codex/hooks.json` → `<repo>/.codex/hooks.json`; `~/.cursor/hooks.json` → `<repo>/.cursor/hooks.json`; AGENTS.md section: local only.
- Copies, never symlinks. Manifest `.wye-kit.json` beside each agent's skills folder (`~/.claude/.wye-kit.json`, `<repo>/.claude/.wye-kit.json`, …): `{ version, files: { "<relative path>": "<sha1-12>" } }`.
- A file whose current hash ≠ the manifest's is the person's: never overwritten, never removed — reported as `edited`.
- Wye's hook entries are recognised by a command that starts with `wye hook`; every other entry is left untouched.
- AGENTS.md section between `<!-- wye:begin -->` and `<!-- wye:end -->`.
- `.wye/config.json` in a repo: `{ "product": "<slug>", "url": "<WYE_URL>" }`; `.wye/session` (gitignored) holds the active external session id.
- A hook never blocks the agent: it exits 0 on every path and prints at most one line when Wye is unreachable.
- The command is `/wye-init` (a skill), not `/wye:init`.
- Commit with an explicit pathspec (`git commit -m … -- <files>`): Wye's own build agents may have staged files in this repo.

## Review Focus

1. **A settings or hooks file that is not valid JSON** (the person edited it by hand) — install must stop for that agent, name the file, and write nothing. → Task 2 test "refuses a hooks file that is not JSON".
2. **Running install twice, or install after the person edited a skill** — no duplicated hook entries; the edited skill is kept and reported. → Task 1 and Task 2 idempotence tests.
3. **Wye not running when a hook fires** — exit 0, one line, no stack trace. → Task 8 test "session-start with no server".
4. **A nested folder inside a linked repo** — `wye` still finds `.wye/config.json` by walking up; outside any repo it falls back to `--product` / `WYE_PRODUCT`. → Task 3 test.
5. **Codex/Cursor `Stop` fires every turn** — it must checkpoint the session, never close it; only Claude Code's `SessionEnd` (or 2 h idle) closes. → Task 7 and Task 8 tests.

'use strict';
// The agent kit (spec docs/superpowers/specs/2026-10-03-agent-kit-design.md): Wye's skills, hooks and AGENTS.md
// section installed into Claude Code, Codex and Cursor, globally or into one repo. Copies with a manifest — a file
// whose hash no longer matches is the person's and is never overwritten or removed; hook entries are Wye's when their
// command starts with `wye hook`. plan() says what would happen; apply() does it. Used by the CLI and by the app.
const fs = require('fs');
const path = require('path');
const crypto = require('crypto');

const AGENTS = ['claude', 'codex', 'cursor', 'agents-md'];
const HOME_DIR = { claude: '.claude', codex: '.codex', cursor: '.cursor' };
const COMMAND = { claude: 'claude', codex: 'codex', cursor: 'cursor' };
const hashOf = text => crypto.createHash('sha1').update(text).digest('hex').slice(0, 12);
const read = f => { try { return fs.readFileSync(f, 'utf8'); } catch { return null; } };

function detect({ home, env = process.env }) {
  const onPath = cmd => (env.PATH || '').split(path.delimiter).some(d => d && fs.existsSync(path.join(d, cmd)));
  return Object.keys(HOME_DIR).filter(a => fs.existsSync(path.join(home, HOME_DIR[a])) || onPath(COMMAND[a]));
}

function targetDirs(target, agent) {
  if (agent === 'agents-md') return null;
  const base = target.scope === 'global' ? path.join(target.home, HOME_DIR[agent]) : path.join(target.repo, HOME_DIR[agent]);
  const hooks = agent === 'claude' ? path.join(base, 'settings.json') : path.join(base, 'hooks.json');
  return { base, skills: path.join(base, 'skills'), manifest: path.join(base, '.wye-kit.json'), hooks };
}

// every file of every skill in the kit: [relative path under skills/, text]
function kitSkills(kitRoot) {
  const out = []; const root = path.join(kitRoot, 'skills');
  const walk = dir => { for (const e of fs.readdirSync(dir, { withFileTypes: true })) { const p = path.join(dir, e.name); if (e.isDirectory()) walk(p); else out.push([path.relative(root, p), fs.readFileSync(p, 'utf8')]); } };
  walk(root); return out;
}
const loadManifest = f => { try { return JSON.parse(fs.readFileSync(f, 'utf8')); } catch { return { version: '', files: {} }; } };

function planSkills(target, agent, o, actions) {
  const d = targetDirs(target, agent); if (!d) return;
  const m = loadManifest(d.manifest);
  for (const [rel, text] of kitSkills(o.kitRoot)) {
    const key = `skills/${rel}`; const dest = path.join(d.base, key); const cur = read(dest);
    if (cur === null) actions.push({ agent, kind: 'skill', path: dest, op: 'write', key, manifest: d.manifest, text });
    else if (cur === text) actions.push({ agent, kind: 'skill', path: dest, op: 'same', key, manifest: d.manifest, text });
    else if (m.files[key] && m.files[key] === hashOf(cur)) actions.push({ agent, kind: 'skill', path: dest, op: 'update', key, manifest: d.manifest, text });
    else actions.push({ agent, kind: 'skill', path: dest, op: 'keep', reason: 'edited', key, manifest: d.manifest });
  }
}

function plan(target, agents, o) {
  const actions = []; const errors = [];
  for (const agent of agents) {
    if (!AGENTS.includes(agent)) { errors.push(`unknown agent ${agent}`); continue; }
    planSkills(target, agent, o, actions);
    if (typeof planHooks === 'function') planHooks(target, agent, o, actions, errors);
    if (agent === 'agents-md' && typeof planSection === 'function') planSection(target, o, actions, errors);
  }
  return { target, agents, actions, errors };
}

function apply(p, o) {
  const done = []; const manifests = new Map();
  for (const a of p.actions) {
    if (a.kind === 'skill') {
      const m = manifests.get(a.manifest) ?? loadManifest(a.manifest); manifests.set(a.manifest, m);
      if (a.op === 'write' || a.op === 'update') { fs.mkdirSync(path.dirname(a.path), { recursive: true }); fs.writeFileSync(a.path, a.text); m.files[a.key] = hashOf(a.text); done.push(a); }
      else if (a.op === 'same') m.files[a.key] = hashOf(a.text);
    } else if (typeof applyOther === 'function') { if (applyOther(a)) done.push(a); }
  }
  for (const [f, m] of manifests) { m.version = o.version; fs.mkdirSync(path.dirname(f), { recursive: true }); fs.writeFileSync(f, JSON.stringify(m, null, 2) + '\n'); }
  return { done };
}

module.exports = { AGENTS, detect, targetDirs, plan, apply, hashOf };

const HOOK_EVENTS = {
  claude: [['SessionStart', 'session-start'], ['SessionEnd', 'session-end --final']],
  codex: [['SessionStart', 'session-start'], ['Stop', 'session-end']],
  cursor: [['stop', 'session-end']],
};
const isWye = cmd => typeof cmd === 'string' && cmd.trim().startsWith('wye hook');
const commandOf = (agent, sub) => `wye hook ${sub} --agent ${agent}`;
function readJson(f) { const t = read(f); if (t === null || !t.trim()) return { ok: true, value: {} }; try { return { ok: true, value: JSON.parse(t) }; } catch { return { ok: false }; } }

// the hooks object with Wye's entries in it exactly once, everyone else's kept
function withWyeHooks(agent, json) {
  const out = JSON.parse(JSON.stringify(json)); out.hooks = out.hooks || {}; if (agent === 'cursor') out.version = out.version || 1;
  for (const [event, sub] of HOOK_EVENTS[agent]) {
    const cmd = commandOf(agent, sub);
    const list = (out.hooks[event] || []).map(g => agent === 'cursor' ? g : { ...g, hooks: (g.hooks || []).filter(h => !isWye(h.command)) }).filter(g => agent === 'cursor' ? !isWye(g.command) : g.hooks.length);
    list.push(agent === 'cursor' ? { command: cmd } : { hooks: [{ type: 'command', command: cmd }] });
    out.hooks[event] = list;
  }
  return out;
}
function withoutWyeHooks(agent, json) {
  const out = JSON.parse(JSON.stringify(json)); if (!out.hooks) return out;
  for (const event of Object.keys(out.hooks)) {
    const list = (out.hooks[event] || []).map(g => agent === 'cursor' ? g : { ...g, hooks: (g.hooks || []).filter(h => !isWye(h.command)) }).filter(g => agent === 'cursor' ? !isWye(g.command) : g.hooks.length);
    if (list.length) out.hooks[event] = list; else delete out.hooks[event];
  }
  if (!Object.keys(out.hooks).length) delete out.hooks;
  return out;
}
function planHooks(target, agent, o, actions, errors) {
  if (!HOOK_EVENTS[agent]) return;
  const d = targetDirs(target, agent); const r = readJson(d.hooks);
  if (!r.ok) { errors.push(`${d.hooks} is not valid JSON — fix it or move it away, then install again`); for (let i = actions.length - 1; i >= 0; i--) if (actions[i].agent === agent) actions.splice(i, 1); return; }
  const next = withWyeHooks(agent, r.value);
  actions.push({ agent, kind: 'hook', path: d.hooks, op: JSON.stringify(next) === JSON.stringify(r.value) ? 'same' : (read(d.hooks) === null ? 'write' : 'update'), json: next });
}
const BEGIN = '<!-- wye:begin -->', END = '<!-- wye:end -->';
function withSection(md, section) {
  const block = `${BEGIN}\n${section.trim()}\n${END}`;
  const re = new RegExp(`${BEGIN}[\\s\\S]*?${END}`);
  return re.test(md) ? md.replace(re, block) : `${md.replace(/\s*$/, '')}${md.trim() ? '\n\n' : ''}${block}\n`;
}
function planSection(target, o, actions) {
  if (target.scope !== 'local') return;
  const section = fs.readFileSync(path.join(o.kitRoot, 'templates/agents-md.md'), 'utf8');
  for (const name of ['AGENTS.md', 'CLAUDE.md']) {
    const f = path.join(target.repo, name); const cur = read(f) ?? ''; const next = withSection(cur, section);
    actions.push({ agent: 'agents-md', kind: 'section', path: f, op: next === cur ? 'same' : (cur ? 'update' : 'write'), text: next });
  }
}
function applyOther(a) {
  if (a.op === 'same' || a.op === 'keep') return false;
  fs.mkdirSync(path.dirname(a.path), { recursive: true });
  if (a.kind === 'hook') fs.writeFileSync(a.path, JSON.stringify(a.json, null, 2) + '\n');
  if (a.kind === 'section') fs.writeFileSync(a.path, a.text);
  return true;
}

function status(target, agents, o) {
  return agents.map(agent => {
    if (agent === 'agents-md') { const md = target.scope === 'local' ? (read(path.join(target.repo, 'AGENTS.md')) ?? '') : ''; return { agent, section: md.includes(BEGIN) }; }
    const d = targetDirs(target, agent); const m = loadManifest(d.manifest);
    const skills = { installed: [], edited: [], missing: [], outdated: [] };

// packages/web/src/lib/agent-kit-view.ts
// What Settings › Agents and the first-run dialog say about each agent (spec §3). Client-safe.
export type KitStatus = { agent: string; skills?: { installed: string[]; edited: string[]; missing: string[]; outdated: string[] }; hooks?: boolean; section?: boolean };
export const AGENT_LABEL: Record<string, string> = { claude: 'Claude Code', codex: 'Codex', cursor: 'Cursor', 'agents-md': 'Any agent (AGENTS.md)' };
export function kitView(list: KitStatus[]): { agent: string; label: string; state: 'installed' | 'out of date' | 'edited' | 'missing' }[] {
  return list.map(s => {
    const k = s.skills; const label = AGENT_LABEL[s.agent] ?? s.agent;
    if (!k) return { agent: s.agent, label, state: s.section ? 'installed' : 'missing' };
    const state = k.edited.length ? 'edited' : k.outdated.length ? 'out of date' : k.installed.length && !k.missing.length ? 'installed' : 'missing';
    return { agent: s.agent, label, state };
  });
}
