# Add right-click context menu to blocks

## Request

> add right click menu to the blocks: delete, comment ...

_from: module:app-documents · refs: rule:document-tree_

## Context

**What you want** — A person editing a document wants to right-click any block (not just a document tree row) to get a menu with Delete and Comment actions, so they can remove or comment on a block directly instead of using separate flows for each.

**Touches** — pr-28: task:pr-28 · app-documents: rule:tree-menu, rule:document-tree · requirements-shell: req:wf2.ui.tree-menu · pages: action:delete-document, action:duplicate-document · requirements-ontology: req:ontology.comment-home · ontology-engine: decision:ontology.comments-in-column, rule:comment-row

**Already there / in the way** — rule:tree-menu already gives Documents-tree rows a right-click/⋯ menu with Duplicate and Delete, but that's rows in the tree, not blocks inside a document req:ontology.comment-home and decision:ontology.comments-in-column already route comments through the context column, not a block-level menu — this request would add a second entry point for the same action no existing rule covers a per-block context menu inside the editor itself, so this looks like new ground rather than a duplicate of rule:tree-menu
