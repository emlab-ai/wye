# Skills

A skill is an instruction a session follows, kept as a document under this page (type:skill): its body is the
instruction, `role:` the session that runs it, `takes:` / `writes:` the kinds it reads and produces. The shipped
prompts are skills here — skill:refine, skill:build, skill:describe-module — read and edit them. A hook runs a
skill on a node (the Hooks document); `skills:` on a PR, a type card or a hook attaches skills to the sessions it
starts. `wye skills` lists them, `wye skill <id>` prints one.
