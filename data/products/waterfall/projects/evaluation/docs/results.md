# Results

Every run the harness made, as cards of this project's types (type:eval-run, type:eval-score, type:eval-pair,
type:eval-public) on the Runs page (module:eval-runs, written by `wye eval` after every run and regenerated by
`wye eval cards`); the tables below are the existing data table and instances view blocks over them — filter, group
and sort them like any type. Nothing here is a page of its own (constraint:wf2.no-custom-pages,
decision:memory.eval-cards-not-a-page). A tier-2 pair's arms stay hidden on its card until every run is marked
(`wye eval compare --pair <id> --mark <arm>-<n>=<1-5>`, or the `mark` property on the eval-pair card); the tier-3
weekly numbers are task:memory.eval-weekly-numbers.
